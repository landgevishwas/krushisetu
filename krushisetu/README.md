# कृषीसेतू – AI सहाय्यित शेतकरी अनुदान अर्ज व्यवस्थापन

मराठी भाषेतील Streamlit MVP. अर्ज नोंदणी, चार-टप्प्यांचा workflow, प्राथमिक AI-सदृश नियमाधारित सहाय्य, अधिकारी निर्णय आणि audit history यांचा समावेश.

## समस्या आणि वापरकर्ते
शेतकरी अनुदान अर्जांवर प्रक्रिया करताना अर्जांची स्थिती, कागदपत्रे, क्षेत्रीय तपासणी आणि निर्णय नोंदी वेगवेगळ्या ठिकाणी राहू शकतात. कृषी सहाय्यक व संबंधित अधिकारी यांना एका स्क्रीनवर अर्जांची स्थिती आणि पुढील कृती दिसावी हा या prototype चा उद्देश आहे.

## Workflow
1. अर्ज प्राप्त
2. कागदपत्र पडताळणी
3. क्षेत्रीय तपासणी
4. अंतिम निर्णय

अधिकारी टप्पा अद्ययावत करू शकतो किंवा कारण नोंदवून अर्ज मंजूर, नामंजूर अथवा दुरुस्तीसाठी परत पाठवू शकतो. प्रत्येक कृतीचा इतिहास SQLite मध्ये नोंदवला जातो.

## AI सहाय्य कुठे आणि का
अर्जाच्या तपशीलातून सारांश, संभाव्य कागदपत्र कमतरता आणि पुढील तपासणीचे मुद्दे दाखवले जातात. सध्याच्या MVP मध्ये हे पारदर्शक नियमाधारित प्राथमिक सहाय्य आहे; प्रत्यक्ष LLM API जोडलेले नाही. हे जाणीवपूर्वक स्पष्ट केले आहे: AI सूचना अंतिम निर्णय नाहीत. भविष्यात अधिकृत योजनेचे नियम, OCR आणि मानवी पडताळणीसह LLM जोडता येईल.

## परिणाम कसा मोजायचा
- अर्ज प्राप्तीपासून निर्णयापर्यंतचा सरासरी कालावधी
- अपूर्ण कागदपत्रांमुळे परत आलेल्या अर्जांचे प्रमाण
- प्रत्येक टप्प्यावर प्रलंबित राहण्याचा कालावधी
- एका अर्जावर कर्मचाऱ्याने केलेल्या पुनरावृत्तीच्या नोंदींची संख्या
- नागरिकांकडून मिळणाऱ्या स्थितीविषयक चौकशींची संख्या

ही मोजमापे प्रत्यक्ष वापरापूर्वी baseline आणि pilot नंतर तुलना करून तपासावीत.

## मुख्य तांत्रिक निर्णय
- Python + Streamlit: एका दिवसात वापरण्यायोग्य web prototype तयार करण्यासाठी.
- SQLite: स्वतंत्र database server शिवाय स्थानिक persistence.
- स्पष्ट workflow states आणि history table: प्रत्येक बदलाचा audit trail.
- नियमाधारित AI सहाय्य: API key शिवाय demo चालतो; AI च्या मर्यादा स्पष्ट.
- Streamlit Community Cloud वर deploy करता येते.

## स्थानिक पातळीवर चालवणे
Python 3.10+ आवश्यक.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

ब्राउझरमध्ये Streamlit ने दाखवलेला localhost पत्ता उघडा.

## Demo
पहिल्या रनला नमुना अर्ज आपोआप तयार होतात. `अर्ज व्यवस्थापन` मधून अर्ज निवडून AI सहाय्य, workflow बदल आणि निर्णय तपासता येतात.

## मर्यादा आणि सुरक्षितता
- नमुना अर्ज व आकडे हे काल्पनिक demo data आहेत.
- हे सरकारी अधिकृत पोर्टल नाही.
- AI सहाय्य सध्या नियमाधारित आहे; कागदपत्रांची सत्यता किंवा कायदेशीर पात्रता पडताळत नाही.
- प्रत्यक्ष नागरिकांची संवेदनशील माहिती या demo मध्ये वापरू नये.
- उत्पादनात वापरण्यापूर्वी role-based access, encryption, backups, server-side validation, audit security आणि अधिकृत योजनेचे अद्ययावत नियम आवश्यक आहेत.
